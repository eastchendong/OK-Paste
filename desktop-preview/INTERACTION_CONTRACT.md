# 当前 HTML 的交互契约

## 2026-10-29 收集交互覆盖规则（优先于下方旧版表格）

桌面收集阶段已按用户新稿重构：默认小头像，空包点击显示 5 秒气泡；有内容显示等宽的紧凑输入框与错落叠卡。点击整叠展开列表，点击单条查看详情，列表右上返回堆叠。鼠标悬停不展开，头像点击收起。旧版「卡片本体切换多选」及「收集阶段直接露出推荐按钮」不再是桌面默认行为；生成任务仍使用整个内容包、支持 @ 引用，工作／结果链路不变。原官方目录仅提供旧交互和基础样式参考。详见 [本轮设计记录](../docs/collection-interaction-2026-10-29.md)。


此表记录桌面预览必须保持的行为，真值来源为 [`components-preview.html`](../components-preview.html) 的完整流程脚本；组件目录中的独立状态卡仅供快速浏览。改动共享界面时先在浏览器原稿重现，再在桌面浮层中操作同一路径。

| 场景 | 触发与结果 |
| --- | --- |
| 两条入口 | “先选素材”与“先选目标”会重置当前演示；前者先加入素材，后者可先选目标再加入素材。 |
| 素材 | 素材行打开就近操作条；加入后内容包展开。卡片本体切换多选；头像看详情；移除按钮只移除该项。选中集合为空时，生成使用内容包全部素材。 |
| 目标 | 同时只有一个目标。替换已有目标须确认；生成中或完成待处理时不能换目标。内容包底部标签可跳转，也可清除。 |
| 拖动 | 拖动选中卡片会带上全部已选素材，否则只带当前卡片；投向演示文档的插入位置。助手与预览组件可从原稿指定的把手拖动，位移受视口边界约束；移动后不触发点击。 |
| 收起与悬停 | 点击助手形象直接同时收起下方推荐方向、内容包与任务面板，再点展开；鼠标离开不收起，悬停不重新打开手动收起的内容。生成时仍可收起，后台任务继续。 |
| 引用输入 | 在文字光标处输入 `@` 才打开菜单；来源候选取自内容包，生成中和调整时取本次运行素材，并附当前目标。上下方向键切换、回车插入、Esc 关闭；引用是不可编辑的结构化标签，可单独移除或跳转。粘贴按纯文本处理。 |
| 方向 | 点击任一推荐方向立即开始生成；自定义方向需有输入，回车发送，Shift+Enter 保留换行。 |
| 生成中 | 可输入补充要求，发送后记录到本次生成；停止会取消演示计时。首次生成停止后返回方向，调整已有结果时停止则返回上一结果，未发送草稿会被保留。 |
| 完成后 | 结果先显示在演示目标中；可展开固定快捷选项或输入要求继续调整，快捷选项点击后直接发送本次调整。撤回回到最近一次待定结果或方向；保留结束本次操作并清理本次素材、目标及撤回历史。 |
| 视觉 | Logo、助手、图标形状、颜色角色、组件轮廓、尺寸、内容顺序、间距和文案与原稿对齐。桌面层只增加真实透底、背景模糊与必要的玻璃高光。 |

## 手动验收顺序

1. 打开桌面 `.app`，确认窗口外没有演示画布，桌面在非组件区域可见；菜单加入素材后内容包展开，鼠标可点到组件外的桌面。
2. 在桌面浮层多选素材、看详情、移除一项；用菜单选择目标。移开鼠标确认推荐方向和内容包仍展开；点击助手形象确认下方内容直接消失，再点击确认展开；生成时亦如此且不停止任务。
3. 在自定义方向输入 `@`，用方向键和回车插入，再删除引用；选择建议启动生成、发送补充、停止，并检查返回阶段。
4. 再生成一次，完成后使用快捷调整、撤回、结束任务；逐项与原 HTML 的完整流程对照。
5. 把浮层移到浅色、深色及彩色应用窗口上方，检查真实透底、文字可读性和边缘效果；对照截图确认形状、尺寸与排版未漂移。

## 真实桌面补充

当前聚焦位置显示在内容包底部，不改变选定执行目标。成功应用后归档本次开始时的整个内容包；取消或失败保留来源，处理中新增来源留给下一任务。撤回已应用修改不重新激活归档内容。

## 状态与任务反馈（2026-10-28 最新）

| 状态 | 小人与反馈 |
| --- | --- |
| idle | 屏幕边缘、低频呼吸，悬停提示随时待命。 |
| 有内容待 paste | 内容包右上，轻微探身，显示待粘贴数量。 |
| working | 独立较高位置，持续动作与处理文案；可以收起面板，任务继续。 |
| 完成 | 小人回到结果旁，一句真实结果；Word、Excel、PowerPoint 结果直接写入原软件，可撤销／继续调整，不再显示独立预览或二次应用。关闭结果结束本次任务。 |

后续调整默认收起，点击「继续调整」展开。已归档来源通过任务引用继续使用，活动内容包保持清空；新的采集留待下一次任务。顶部菜单的设置是真实原生 API Key 与快捷键配置，不把开发演示入口放入菜单。
