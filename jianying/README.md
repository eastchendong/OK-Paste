妥帖复用 [capcut-mcp](https://github.com/yeroshalmiariel-ai/capcut-mcp/tree/2859abf0d2905df0020d7079408be5ce8d2186cd) 的本机 stdio 工具与 [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft) 0.3.1，完整版本固定在 `../requirements-jianying.txt`。不启动上游 HTTP／远程授权服务。capcut-mcp 的 MIT 声明保存在 `LICENSE.capcut-mcp`。

```sh
cd prototype
pnpm run setup:jianying
```

聚焦剪映（本机 bundle `com.lemon.lvpro`）后，推荐读取当前活动内容包、真实前台窗口和可读取的工程元数据。复制视频文件或可下载的视频时，会围绕实际播放时间读取四秒片段并抽帧；无法访问的 blob 视频明确标为未读取，不能冒充已经观察了特效。抽帧需要 PATH 中的 FFmpeg／ffprobe。

模型通过实际工具目录组合剪辑、转场、关键帧、滤镜及特效。`list_effects` 与 `describe_effect` 返回真实名称、资源 ID、参数和 VIP 信息；不生成随机资源 ID。`mcp_server.py` 补上上游在片段加入轨道后再添加转场／特效／动画时漏写素材表的问题。

修改先在 Application Support 的 `.local/jianying-previews/` 生成独立草稿，确认后添加一个新的「妥帖复刻」工程。已有工程不覆盖。撤回只归档本次生成且没有被剪映改动的工程，并保留根索引其他字段和项目。测试使用临时目录与合成素材，不向现有工程塞测试内容。

2026-10-30 适配 `wanyiran1029` 的组件源码与完成态：提供视频专用快捷调整，确认文案为「添加新草稿」。安装草稿时将真实引用的音视频复制到工程内并改写路径；采集缓存移除后草稿素材仍可用。新版加密元数据时使用根索引辨认工程，根索引写入真实内容文件路径并同步项目 ID 列表。真实 MCP 检查验证资源 ID、素材复制、应用与撤回；真实剪映首页已出现 4 秒合成测试草稿，进入时间线与播放效果仍未通过验收。

当前边界：本机剪映 11.6 的已有 `draft_info.json` 是非 JSON 内容。适配器不能读出其中的实时播放头、选中片段、已有转场，也不能直接在加密时间线上插入。当前实现是**独立复刻草稿**；没有完成该版本剪映原生窗口中的打开、资源下载和效果播放验收，不把结构检查称为视觉效果验收。没有提供目标素材时，Agent 应先询问素材，不能只导入参考原片就声称已复刻。
