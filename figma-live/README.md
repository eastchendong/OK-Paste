## 配置与使用

1. 启动妥帖，本机 HTTPS 文档桥使用既有 localhost 证书，监听 `127.0.0.1:47722`。
2. 首次在 Figma 桌面端通过 Plugins → Development → New plugin 创建 Figma design／Custom UI 插件，保存到上述目录；不要手工编造插件 ID。
3. 在 `prototype` 运行 `pnpm run setup:figma`。已有自定义目录时运行 `node scripts/prepare-figma-plugin.mjs ~/figma-live-plugin`。它保留 Figma 分配的 ID，更新代码、UI 和清单；不会覆盖旧 `.local/figma-plugin/`。换电脑需先创建开发插件。
4. 在一个新的空白 Design 文件运行「在空白文件建立测试画布」。它仅允许全文件所有页面都为空，建立瓶子／杯子／新角色三个原生画框。
5. 在当前文件运行「连接妥帖」，插件会自动接通；妥帖未开时会等待，之后自动重连。保持插件运行，向内容包加入参考照片。
6. 选中目标画框，在画布按 ⌥⌘V，输入要求或直接发送当前一条默认推荐。生成并检查后写入该画框，之后可补充要求或逐级撤回。

第一版只支持**页面顶层、未锁定、未使用自动布局的单个 Frame**。鼠标位置用于摆放妥帖浮窗；生成位置由捕获的画框对象决定。

## 读取和写入边界

- 读取当前页面的图层结构、可用几何、文字、填色和描边；全文件其他页面只读目录，不能声称已经理解其他页面内容。最多 3000 个节点／4 MiB 结构数据，超过直接拒绝。
- 视觉上下文为目标画框及距离最近的两个非空参考画框，再加内容包来源图片。预览缓存跟随页面版本，导出中页面变化则重新捕获。
- 模型只提交受 Zod 约束的路径、椭圆、矩形数据；共享编译器生成 SVG，Figma `createNodeFromSvg` 负责创建原生图层。暂不生成渐变、位图、文字、蒙版或复杂外观。
- 新结果是目标画框内的独立节点；不修改原有角色。写入前再次检查页面版本。继续调整时先准备新结果，再替换上次结果；失败保留旧结果。
- 撤回恢复本任务上一成功版；撤回第一版才删除本任务作品。用户另加的兄弟节点保留；手动改动、移动或删除自有结果后拒绝覆盖／删除。写入回执不确定时冻结该任务，不能通过取消重试写入。
- 开发版按前台 Figma 文件名匹配唯一连接，只保留当前文件的插件连接，并使用不同的文件名；不把它宣称为基于文件 key 的跨文件身份校验。插件重启后的事务恢复尚未实现。

## 实现

`host.js` 仅开放固定文档动作；`ui.html` 把插件消息转交给本机 HTTPS 子页，仅将待处理命令的宿主回执转回子页。清单只允许开发模式访问本机 HTTPS 地址，不开放任意网络域名。`VectorLiveTarget` 共享矢量准备、冲突检查、写入与撤回状态；Figma 和 Illustrator 只提供各自的宿主边界。

官方远程 MCP 现在也支持写入，但自建客户端接入受 Figma 客户端目录约束；当前产品优先采用直接对应当前文件和选区的 Plugin API。后续可另做远程 MCP 适配器，不能把 Codex 能调用某连接等同于妥帖产品已接入。
