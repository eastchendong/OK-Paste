# 妥帖 · 图片右键采集

在 Chrome 的图片原生右键菜单中提供「添加图片到妥帖内容包」。它只在用户点击菜单时读取该图片与来源，不注入另一套文字划词弹窗，不需要重建或重新签名桌面宿主。

## 构建与使用

1. 在 `prototype/` 中运行 `node scripts/build-image-extension.mjs`。
2. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，选择构建脚本准备的 `~/Library/Application Support/Tuotie/extensions/image-menu` 目录。也可选源码中的此 `browser-image/` 目录。扩展需要浏览器授权，不由构建脚本自动安装。
3. 保持妥帖桌面应用运行。在真实网页的图片上右键，选择「添加图片到妥帖内容包」。
4. 页面提示保存结果；悬浮球的内容包显示真实图片缩略图，并保留页面标题、网址及图片地址。添加图片不会自动确认生成或应用修改。

普通 HTTP/HTTPS 图片由扩展读取，可跨图片 CDN；页面内的 blob 图片先从实际所在 frame 读取。图片大小上限为 6 MB，无法读取或超限时会提示失败，不用一个地址冒充已保存的图片。登录、防盗链与浏览器限制仍可能阻止个别图片读取。系统复制失败但图片已经落盘时会明确显示已添加，不要求用户重复保存。

0.1.2 增加 PNG/JPEG/GIF/WebP 文件签名识别：图片 CDN 即使返回通用二进制类型或缺少类型，也可按真实内容保存；HTML 错误页和未知二进制仍拒绝。安装不需要重启 Chrome；更新本地文件后，在扩展管理页点击本扩展的重新加载按钮即可。

菜单仅用于 HTTP/HTTPS 网页的图片。Chrome 内部设置页、CSS 背景、Canvas 与视频画面不属于本次入口。Safari 需要另外实现对应的浏览器扩展。

权限用途：`contextMenus` 添加菜单；`activeTab` / `scripting` 在用户点击后读取所点击图片及显示结果；HTTP/HTTPS 访问用于读取跨站 CDN 图片并连接本机 `127.0.0.1:47721` 服务。扩展不携带模型密钥。

来源应用由采集客户端直接保存。本包面向 Chrome，记录 `Google Chrome / com.google.Chrome`，不依赖桌面前台轮询、窗口标题、辅助功能授权或默认浏览器。若移植至 Edge／Arc，必须在 `installImageContextMenu` 传入对应应用身份，再构建该浏览器专用包；不能把 Chrome 构建直接当作通用浏览器版本。更新本地扩展文件后需要在 Chrome 扩展管理页重新加载。
