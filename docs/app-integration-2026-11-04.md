## 使用入口与写入范围

先在来源应用选择文字或可复制图片，按 **⌥⌘C** 加入内容包；网页划词的“加入内容包”和图片右键扩展也保留。普通 ⌘C/⌘V 不被接管。随后使用下列目标入口。

| 目标 | 入口与结果 | 条件和边界 |
| --- | --- | --- |
| Word | 打开妥帖加载项，在正文放光标，按 ⌥⌘V；发送后插入固定位置，支持继续调整和逐级撤销 | 图文/段落格式限段首或空行；句中保留纯文字；只编辑本任务新增范围 |
| Excel | 打开加载项，选择连续单元格区域，按 ⌥⌘V；写入固定矩阵并可逐级撤销 | ExcelApi 1.13；合并、数组/溢出、结构化表和受保护工作表会拒绝；原格式保留 |
| PowerPoint | 打开加载项，选择图片、头像空位或单段文字框，按 ⌥⌘V；修改固定对象并可逐级撤销 | 不支持任意复杂富文本/动画；中文文字需有明确字体；重建图片 ID 可改变 |
| Figma | 运行“妥帖 · 矢量创作”，选中一个支持的 Frame，按 ⌥⌘V；真实候选渲染和模型检查后写入 | 页面顶层、未锁定、无自动布局的单 Frame；当前生成路径、椭圆、矩形，不含文字/位图；支持多版本撤销 |
| Blender | 保持 MCP 插件连接；聚焦生成建议、拖入内容包，或 ⌥⌘V 冻结视口中心后确认；预览后应用，可见结果交给独立桌面 overlay 标明 | 保留独立预览、取消、应用和撤回；不是图片重建三维，也不是任意场景碰撞保证；物理入口完整体验仍待验 |
| 已保存 DOCX/XLSX/PPTX | 菜单选择目标文件；独立副本预览后确认写回 | 与加载项实时编辑是两种入口；完成后保留该文件用于下一包资料，不能声称读取原生未保存状态 |
| 普通文字应用 | 聚焦目标，选择生成方向；确认后复制生成文字，再在目标中正常 ⌘V | 不自动发送聊天/邮件，不宣称已原位写回任意第三方编辑器 |
| Illustrator | 保留捕获画板和矢量适配器，入口为 ⌥⌘V | 实验能力，尚缺真实 Illustrator 宿主验收；没有 Figma 同等多版本/看图保证 |
| 剪映/CapCut | 显示“接入暂未启用，内容包已保留” | 不规划、不启动 MCP、不写草稿；切换其他应用可继续。已有其他 App 的固定任务不因焦点切到剪映而改变 |

Office/Figma 一次唤起固定一次目标。点击其他位置或跨应用不会悄悄改变本任务；需要换目标时先结束任务。生成失败/停止保留上一成功版，写入结果不确定时冻结并要求检查原稿。版本链在内存中，结束任务或服务/加载项重启后不能恢复旧撤销历史。

## Figma 安装和保留能力

- 正式命令 `pnpm run setup:figma` 指向 `scripts/prepare-figma-plugin.mjs`，默认输出 `.local/figma-live-plugin/`。先由 Figma 登记真实开发插件 ID；脚本只更新该身份对应的资源。
- 已有本机安装继续用原目录，例如 `node scripts/prepare-figma-plugin.mjs ~/figma-live-plugin`。复用现有证书、插件 ID 和辅助功能授权，不重复登记或修改系统信任。
- dev 的 `figma/`、`src/figma/` 与 `targets/figma.ts` 保留。显式开发命令 `setup:figma-mcp` 使用 `.local/figma-mcp-plugin/`，保留已有 ID，不覆盖 `.local/figma-plugin/` 或正式 live 插件。
- 运行资源同步不再自动执行旧 MCP setup。桌面聚焦只沿用新版路由，旧 MCP 不启动、不占用默认任务。文字、图片、布局工具尚未迁入正式矢量协议，因此 UI 不显示已经拥有这些能力。
- 将来扩展优先迁入同一捕获目标/事务协议；不能只把旧工具挂到新 UI 就宣称具有多版本、未知写入保护或强制视觉验证。

## 合并修复

1. Swift 宿主和 UI 以 wanyiran 为主，保留 workRevision、服务重连、固定目标、草稿和逐级撤销语义；从最终 UI 源重生成 HTML、浏览器/Swift 组件和 overlay。
2. 剪映采用独立 disabled 状态，既不退回文本生成，也不误显示“复制到系统剪贴板”作为替代动作。后端拒绝执行，界面没有生成/写入按钮，参考内容不归档。dev 的素材自包含、索引及版本保护保留在未启用的适配器中。
3. 外部 Office 文件检查发现 `finish` 释放目标后下一包停在 idle；现对没有前台焦点的已选文件重新建立目标，实时 Range 仍必须重新捕获。原回归用例已通过。
4. Vitest 的发现范围限制为 `tests/`，避免 `.local/` 中历史源码导出被误当成第二套测试执行。
5. 新增 `build.sh --package-only`，用于编译与重建仓库 ZIP，不更新 Application Support、不安装或重启日常应用。
