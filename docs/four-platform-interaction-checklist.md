Word 的原生 ⌘Z 会保留段落标记的 `w:rFonts w:hint="eastAsia"`，即使文字恢复，严格版本比较仍可能拒绝妥帖撤销；本轮保留保护规则，没有放宽格式比较。最后通过结束任务、原生删除测试片段恢复合成稿，正文及段落文字/样式一致，但不宣称 OOXML 完全一致。普通两版逐级撤销已在前一轮独立通过。

PPT 对比排除重建图片 ID，不承诺文件字节一致。Figma 图层定位应点击名称文本叶节点，容器行的 bounds 可能含后代；⌘R 打开 Layer name 后用 AX setValue 改名，先回读身份与修改结果。测试中外层画框被使用者改名时，撤销只移除自有结果并保留该改名；后来已恢复原画框名。

修复并回归：共享 Office/Figma 串行传输保留会话、批次和待确认回执；丢回执不重放编辑，超期命令执行前拒绝。Figma 初始页面失败时仅在没有宿主操作期间重试。原生服务 watchdog 单次启动、退避并复用日志句柄。运行标识变化结束旧 UI 与原生等待；停止后旧等待回调不能结束新任务。默认推荐缺失只向模型纠正一次，不伪造文案。V0 不再自动规划，finish 在异步 release 前解除目标引用，防止轮询读到已失效锚点。收集态清除旧任务目标行；正在等写入/撤销回执不误报未知结果，成功后清空已发送调整文字，真正未知结果只读。
