# 当前页补齐画像头像
用户已确认：同一页三个画像、一个已有头像、两个待补齐；点击当前页并按 ⌥⌘V，无需选择对象。限演示版式。
采用当前页结构识别 + 既有多模态规划 + 本机图片去背 + 原有写入撤销。页面入口只允许识别出的两个空位，保留已有头像与文字。显式选择对象的旧流程兼容。
识别基于当前页形状：一个参考图片、两个无文字且与参考图片尺寸比例相近的空位；未满足条件时清楚提示，不扩大为整页编辑。冻结 slideId 与目标对象 ID。
第一次推荐为单条补齐头像意图；生成模型结合截图、姓名、来源标题匹配两张图片，不通过收集顺序推断人物身份。对应不明确时要求澄清，不自行猜姓名。
去背仅发送后执行，独立本机 Vision helper，透明 PNG，contain 放入原空位；失败禁止带背景写入。先准备全部图片，再复用原有 apply/undo。多对象写回现有非原子限制保持可见。
不扩展通用排版、任意新增坐标、整页重设计。Excel 本轮不改。
