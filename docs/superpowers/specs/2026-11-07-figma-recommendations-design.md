# Figma 三类聚焦场景推荐
用户已在本 chat 确认方案并要求开始实现。范围：同系列角色补全、同风格图标补全、同产品空状态插画。

首轮沿用独立 DeepSeek 单请求，仅一句默认要求，允许用户自行改写。资料决定主体/语义，首次目标与参考画框决定风格。新增 vector 输出与 vector-artwork 场景，不伪装成插入位图。模型可返回 vector-character / vector-icon / vector-empty-state 场景元数据；不确定则失败自行输入，不猜主体，不用旧模型补调用。资料刷新沿用冻结首次目标与图片。无配置的旧安装保持旧入口兼容。

执行仍为 prepare_figma_artwork → 实际渲染 → review_figma_artwork → 原位写入。三类任务共用矢量工具，保留 path/ellipse/rect、平涂、固定顶层非自动布局 Frame、版本与所有权保护。不新增文字、位图、布局、组件或原图层编辑。

二轮在成功交付后后台生成 0–3 条 label/instruction/direction。仅调本任务作品，保留用户最新约束，按当前作品与真实成功版本图片给可选变化，不把生成错误包装为优化。角色：造型/表情/细节；图标：简化/视觉重量/符号表达；空状态：简化/情绪/主体强调。无需凑数，不重复刚完成变化，不主动推翻系列风格。初始参照冻结，当前结果从目标读回。沿用取消/迟到丢弃/按版本缓存与撤销恢复。输入框空时点击执行，有草稿时追加并等发送；失败/未知场景只保留输入，不伪造固定建议。

验收：单次推荐与 vector 能力校验；三场景与非矢量隔离；冻结视觉/资料刷新；真实矢量工具、成功回读与版本图片；迟到/撤销/结束；DOM 按钮、草稿与一次 continuation。真实模型用合成材料验语义；不以自动测试代替真实 Figma 宿主验收。
