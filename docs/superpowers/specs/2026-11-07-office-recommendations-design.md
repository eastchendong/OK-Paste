# 表格与 PPT 首次推荐（当前唯一开发范围）
Excel：零散资料整理为表格、按已有表头追加记录。读取固定选区和工作簿，单次 DeepSeek 返回一条推荐。
PPT：当前页三个画像、一个已有头像、两个待补齐；点击页面后唤起即可。读取当前页形状、文字、截图，结合内容包图片推荐补齐。无对象选择时只读当前页，不能因此授权整页写入。
只开发推荐输入适配、场景模板与原版推荐接线；不实现去背，不扩大写入范围，不修改生成/撤销。此前 ppt-persona 设计与实施计划中执行部分暂停。
沿用首次快照、内部最多三个候选只展示一个、失败自行输入、用户草稿不触发重算。场景由显式适配类型提供；软件名本身不是用户意图证据。
