## 2026-11-07：表格与 PPT 首次推荐扩展
- 共用原首次推荐链路，一次 DeepSeek 请求、一次返回校验；新增可选 scenario：spreadsheet / persona-slides。Word/input-live 不变。
- Excel 输入来自固定选区与工作簿；只做资料整理成表格、按已有表头追加记录。不新增行列或修改执行工具。
- PPT 输入来自当前页全部对象/文字/截图与内容包图片；只做三个画像中补齐两个头像的意图推荐，不实现去背和填图。
- 无对象选择时 PowerPoint captureScope=page；固定原页但 selectedShapeIds=[]。推荐可显示，发送禁用，后台 run 同样拒绝；不将读整页视为写整页授权。原有显式选中对象入口保留。
- 图片单项 base64 上限从 2M 调整为 4M 字符以容纳既有画像素材；总输入 6M 上限保持，超限自行输入，不静默截断。
- 真实接口使用虚构资料：空表招聘记录约 1.025 秒，已有表头报名记录约 0.977 秒，既有双头像+目标页截图约 2.081 秒；均仅模型请求，不是快捷键到显示的完整延迟。
- 原生 Office 当前页捕获尚待用户实机复验；重开 PPT 加载项以载入 v3 adapter。旧演示图片本身已透明，不把这次推荐测试当成去背能力验收。

第二轮真实调用：Excel 追加 967 ms，PPT 图片 2990 ms，无图片 PPT 466 ms。发现一次把四列说成四条记录，模板已明确禁止在推荐中填写记录数，避免字段数与记录数混淆；PPT 延迟目前不能保证 2 秒内。
