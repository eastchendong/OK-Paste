# Excel 与 Figma 修订工作流 · 2026-11-03

两端沿用 `FileRunner` 的固定目标、候选／成功版本、完成页、草稿保护和逐级撤销。没有增加 LangChain／LangGraph 或新的运行依赖。模型生成数据，宿主检查范围、版本和所有权，程序决定写入与任务状态。

## Excel

- `ExcelLiveTarget` 准备完整选区矩阵，生成／停止／失败均不先撤旧版。每个成功版本对应一次宿主回读；撤销 V2→V1→V0，只恢复固定区域，保留其他区域编辑。
- 单元格可为数字、布尔值、null（清空），或 `{formula:"=B2*2"}`／`{text:"=待核对"}`。兼容旧的 `=…` 公式字符串，其他字符串按文字写入，避免 `+`／`-` 等被 Excel 当公式。`formulaMask` 来自宿主实际公式区域，撤销时也保留文字与公式的区别。
- 写入前检查完整工作簿版本、预期修订号，以及上一次实际写入的选区内容、公式类型、地址和数字格式。用户手改本任务选区时拒绝覆盖／撤销；数字格式等原格式不主动重设。
- 要求 ExcelApi 1.13。暂时拒绝受保护工作表、已有数组／溢出区域、相交合并区域及结构化表，避免部分修改或表格自动填充超出选区。合并检查查询工作表完整使用区域，覆盖合并区域左上角在选区外的情况。能力检查失败不降级为无检查写入。
- 写入后回读实际结果；返回的计算错误单独提示，并保留撤销入口。它不是公式业务正确性的证明，也不保证模型生成的新公式不会产生依赖、外部链接或动态数组副作用。复杂公式规划和独立计算预演尚未实现。

## Figma

- 新作品仍是受约束的 path／ellipse／rect 矢量数据，不允许模型执行 Plugin API 脚本、传入任意 SVG 或网络资源。继续调整上下文包含上一成功版 `currentArtwork`。
- 每次准备在原目标画框的临时克隆中导入候选，移除克隆中的上一版自有作品，保留参考背景与其他对象，导出真实 PNG，随后在 finally 中移除临时画框；原画布版本改变则拒绝候选。
- 通用工具循环把 PNG 作为图片消息传给模型，不把 base64 当成 JSON 文本。模型必须看图并调用 `review_figma_artwork`，核对最新随机 candidateId；修改候选后检查结果失效。检查通过直接结束工具循环，不再额外请求一次模型总结。未通过最新候选检查不得写入。最多 6 轮，预算耗尽保留旧版；不保证模型的主观视觉判断总正确。
- 新版在导入、验证成功后才替换旧作品。宿主保存每版 SVG、位置、尺寸和图层顺序，撤销时先重建上一版，再删除当前版。V1→V0 仅删除本任务作品，原图层和用户另加兄弟节点保留。重建会改变生成节点 ID，不承诺 ID 不变。
- 自有作品被手工修改、移动或删除后拒绝覆盖／撤销。页面顶层、未锁定、非自动布局 Frame 的限制继续有效；读取范围仍为当前页面，其他页面只有目录。当前仍不编辑原有文字、图片或任意布局。
- 开发测试菜单可在指定合成测试文件新建「04 · 修订验收」空画框；不在正式稿运行，不清空已有画框。更新清单后 Figma 可能需重新导入同一 manifest 才刷新开发菜单。

## 共同边界与验收

宿主明确返回 `mutationStarted=false` 时，旧版及撤销能力可继续使用；回执丢失或写入后的故障冻结任务，不自动重放，也不承诺自动回滚。宿主和客户端都检查修订号以拒绝重复提交。每任务最多 20 版，记录在内存，插件／加载项／服务重启或结束任务后不恢复。

`scripts/excel-figma-revision-check.ts` 是开发验收入口，代替常规服务启动，使用独立内容库和真实模型。Excel 只接受 `excel-revision-check-*` 目录中的指定合成稿 B2:C3；Figma 只接受指定测试文件中命名为「04 · 修订验收」的空画框。保存两轮结果并逐级撤销；未知写入不重复应用。此程序不代表物理快捷键或宿主自带 ⌘Z 已通过。

接口依据：[Excel Range](https://learn.microsoft.com/en-us/javascript/api/excel/excel.range?view=excel-js-preview)、[Figma FrameNode](https://developers.figma.com/docs/plugins/api/FrameNode/)、[Figma exportAsync](https://developers.figma.com/docs/plugins/api/properties/nodes-exportasync/)。

## 最终验证结果

174 项后端检查通过（10 项外部环境跳过），62 项桌面检查通过，TypeScript、UI 生成物及 diff 检查通过。真实 Excel 与真实模型完成两版及两次撤销，公式结果 240.00→450.00，公式样文字保留为文字，其他区域和原数字格式恢复。

真实 Figma 与真实模型完成浅蓝色瓶子→浅绿色瓶身、最新候选实际渲染检查及逐级撤销；原有图层保持，第一版属性恢复一致，第一版／原空画框恢复 PNG 的最大通道差均为 0。首次严格比较发现缩放舍入误差，已改为保留原缩放参数并重新完成完整联调。开发验收脚本等待时间超时或插件重开断连不记为通过。测试后恢复原稿、释放目标，来源仅在隔离库中。去内容证据见 [验证记录](evidence/excel-figma-verified-2026-11-03.json)。
