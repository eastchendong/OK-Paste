# Figma 三类聚焦场景的一轮与二轮推荐

## 产品行为
- 首轮在角色补全、图标补全、空状态插画三类目的中识别一类，只展示一句默认要求。来源决定主体/语义，首次目标画框和相邻参考画框提供样式与用途依据；不凭应用名称或空画框猜角色。
- 复用原版 IP、浮窗、内容包、@与发送。用户要求优先；资料刷新沿用冻结的首次目标和图片。用途未知、模型失败或超限时自行输入，不追加旧规划请求。
- 新增 vector 输出能力，仅 Figma 矢量入口接受；不将可编辑矢量等同插入位图。不配置独立推荐 Key 的旧安装保留旧规划兼容路径。
- 用户发送后继续调用原矢量准备/实际渲染检查/原位写入，无新增人工确认步骤。图标、空状态不再强制套角色模板。
- 写入成功先显示完成反馈，再后台生成0–3条可选调整。根据真实成功版本 artwork、当前目标回读 PNG、首次冻结的样式参照和本次所用资料生成，不读后来收集的下一任务资料。
- 角色方向：造型比例、已有五官表情、装饰简化；图标：简化、视觉重量、已确认符号强调；空状态：简化、已有情绪、主题强调。语义适用性依赖模型；场景与能力/维度白名单、去重由程序校验。
- 不重复已完成变化，不推翻最新用户约束；风格不一致、错位、裁切、必需项遗漏是执行校验问题，不能当成可选优化。
- 空框点建议直接发送完整要求；有草稿则追加并等待发送。动态刷新保留编辑节点、焦点和输入草稿。
- 建议绑定目标/版本/请求代次，结束或新修改取消旧请求，撤销恢复该版缓存。无候选/失败/用途未知时保留自由输入，Figma不退回固定矢量按钮。Illustrator不迁移。

## 模块
- initial-recommendations.ts 将 Figma固定目标、当前页结构与首次视觉输入适配给现有 core/provider。
- recommendations/core.mjs 增加 vector-artwork 场景、vector 输出与可选于非矢量的场景元数据；vector 输出必须带三个合法 scene 之一，否则自行输入。
- FileRunner 保存初始目标视觉，消费首轮场景提示；成功写入后读回 currentArtwork/当前画框 PNG，复用原后台请求和版本缓存。
- followup-scope.ts / followup-recommendations.ts 扩展三类场景，不新增编辑工具。
- AgentClient 的 Figma规划/执行指令泛化为三类作品；共享 task-panel 显示动态选项。

## 已有任务面板恢复
“请先在妥帖结束当前任务”来自已有目标占用保护：后端仍持有任务，但前端面板丢失时，旧逻辑会重复捕获。现在快捷键恢复入口与菜单“显示内容包”先恢复已有任务的画框、阶段、结果和实际执行资料，不重复捕获，也不直接发起生成。恢复运行中任务后可停止；恢复首轮可发送；恢复成功版本可继续调整和撤销。结束任务后才能改选新目标。版本记录仍只保留在当前后端会话内。
FileRunner 的 executionSourceIds 区分“规划时看见的资料”和“本轮真正选用的资料”，提交版本一并保存，撤销随版本恢复；面板恢复不能把其他未选资料加入下一轮。paste-resume.mjs 覆盖11项界面行为，figma-followup-workflow 覆盖实际执行资料与版本恢复。

## 不变的边界
页面顶层、未锁定、非自动布局的单个 Frame；只生成 path/ellipse/rect 平涂矢量；只替换本任务作品，不新增文字/位图/渐变/组件、不改原图层或整页布局；最多20版，记录不跨重启恢复。保留真实看图检查、版本/所有权冲突与未知写入冻结。
