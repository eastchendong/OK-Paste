# 妥帖跨 App 桌面 overlay SOP

更新：2026-11-05。本文是用户明确的产品原则与实现／验收要求，不表示所有条目均实机通过。通用 NSPanel 桌面层已实现、检查并安装，当前只有 Blender 提供真实生成区域；其他 App 区域适配、物理入口和完整桌面体验仍待追加。分层证据见 [本轮检查](evidence/desktop-overlay-2026-11-05.json)。

## 统一责任

高亮、虚拟 cursor、遮罩由妥帖拥有的独立原生桌面 overlay 绘制，跨 Blender、Figma、Office 及后续 App 复用同一套生命周期与视觉规则。目标 adapter 只报告真实生成区域和定位事实，不负责绘制妥帖产品反馈。

禁止通过 Blender GPU／视口 draw handler、Figma canvas／图层、Office 文档／形状／单元格样式绘制产品反馈；也不能向用户内容写入临时高亮对象、材质、文字、标记或遮罩。此前 Blender 内部 GPU 方案已被用户否定，不能重新接回产品或计入桌面 overlay 成果。

虚拟 cursor 是视觉指示，不是系统鼠标。不得移动系统鼠标、合成点击／按键、改变用户选区或编辑位置。overlay 不成为 key window、不捕获键盘输入，其视觉区域鼠标穿透；既有确认／撤销控件保持各自明确的可交互区域。生成完成后按用户要求激活对应 App 与结果位置，与 overlay 窗口自身的激活行为分开处理。

用户提出 ChatGPT 的虚拟 cursor／Tophat 作为参考机制。本机未发现可调用的 Tophat API，未验证其内部机制。可以参考用户描述的体验，不得宣称调用、集成或复现了 Tophat 的内部实现。

## adapter 输出与信任检查

adapter 必须从当前真实结果读取几何，不得让模型猜屏幕位置。协议至少明确以下事实；具体字段名以实现为准：

| 事实 | 必须能判断什么 |
| --- | --- |
| 任务与结果身份 | 当前 runtime／task／revision、preview 或 applied 阶段，避免重播旧结果 |
| 目标 App 与窗口身份 | bundle ID／进程及可核验的窗口关联，避免把另一窗口当作结果窗口 |
| 区域与坐标系 | 矩形或轮廓属于目标窗口的哪块真实内容区域，原点方向、单位和参考尺寸明确 |
| 读取时的视图状态 | 窗口／视口尺寸、页面／场景／视图版本或等价有效性依据，明确何时必须重读 |
| 有效性 | 可见性、边界、读取时间与不可用原因；数值有限、尺寸为正且范围有界 |

原生宿主核对任务、窗口与几何有效性后才能绘制。外部内容、网页文字、模型回复及旧拖放点都不能成为可信结果坐标；拖放点只用于原任务定位，不能冒充最终生成对象范围。无法得到可信几何时保留真实结果与正常应用／撤销操作，使用准确的简短状态说明，不在任意位置画框或虚拟 cursor。

## 坐标与显示器

1. 将 adapter 的局部坐标映射到当时核验的目标窗口／视口，再映射到 AppKit 全局桌面坐标；坐标转换集中处理，不让不同 adapter 各自猜原点。
2. 显式处理窗口内容区、标题栏及视口偏移、Y 轴方向和缩放。Retina 的像素与 point 不混用；使用实际窗口所在显示器的 backing scale，不能固定乘二。
3. 支持显示器位于主屏左侧／下方等负全局坐标及不同缩放比例。只在目标结果所在的可见屏幕区域显示，遮罩裁到真实目标窗口／内容区域，不暗化无关 App 或整片桌面。
4. 窗口移动或缩放、跨屏、缩放／滚动／旋转视图、切页／切场景后，核验旧几何是否仍有效。能可靠重映射或重读才继续；否则立即隐藏并等待新的真实几何，不能让旧框追着错误内容移动。
5. 目标窗口最小化、关闭、被切到其他 Space，或当前可见区域属于另一 App 时隐藏对应反馈；不把旧标记悬在新前台窗口上。

## 任务生命周期

1. 捕获：拖入与 ⌥⌘V 都记录真实目标和位置语义。视口中心必须标为中心射线，不能写成鼠标落点。捕获不执行模型修改，迟到捕获不能复活已取消／切换的任务。
2. 规划与确认：只展示当前内容包、目标和版本匹配的候选；明确任务仍保留显式确认。overlay 本身不触发生成、应用或提交。
3. 结果就绪：先得到真实预览或应用回执，再读取对应结果几何。每个有效结果最多触发一次短暂定位反馈；反复轮询、初次恢复快照、重启或断线重连不能重播旧动画或反复抢回目标 App。
4. 绘制：原生独立桌面层统一显示轮廓、轻遮罩与可选虚拟 cursor。指示对应真实生成区域，遵守系统减少动态效果设置；动画不延迟输入、不接管系统鼠标。
5. 失效：取消、撤回、任务切换、版本变化、宿主退出、窗口失效、超时或断连时撤销相应反馈。旧 token 的迟到成功或失败回调不能清除新任务的 overlay，也不能重新显示旧任务。
6. 清理：超时自动移除视觉窗口、计时器和监听；清理可重复执行。反馈获取／绘制／清理失败不取消已经成功的场景或文档事务，不伪称写入失败，也不妨碍用户应用、撤销或继续调整。

## 权限与部署

只做现有屏幕录制／辅助功能授权的状态预检；缺权限时说明哪项真实定位信息不可获得，提供用户主动打开设置的入口，不循环弹授权请求，不修改 TCC 或扩大权限。没有所需权限时不拿占位几何继续显示反馈。

HTML／JS／TS 变更按既有 runtime 同步流程部署；新增或修改 Swift 原生层时复用现有持久签名身份、bundle ID 和授权登记，不重新初始化证书或默默退回 ad-hoc。重启前核对活跃预览／撤销状态，保留用户工程、内容包和本机配置。

## 验收与证据

| 场景 | 应观察到的结果 |
| --- | --- |
| 正常 preview／applied | 指向本次真实结果；阶段准确；只短暂展示一次 |
| 原生层独立性 | 关闭 overlay 后目标内容／几何／材质／选区与显示前一致；目标文档中没有反馈图层 |
| 跨 App 与输入 | Blender／Figma／Office 共用桌面层；真实鼠标和键盘持续可用；不合成点击 |
| 窗口与多屏 | 移动／缩放／负坐标／混合 Retina 下正确映射或及时隐藏，不把旧标记留在别的 App 上 |
| 生命周期竞争 | 取消／撤回／切任务／迟到回调／轮询／重启不复活旧反馈，不误清新反馈 |
| 缺权限／无几何／失败 | 不伪造位置，原结果与撤销仍可用，视觉层能清理 |

先用确定性几何和生命周期检查核对映射与清理，再用隔离合成结果进行原生可见性检查。真实模型＋MCP 场景事务、离屏渲染、原生桌面可见效果、物理拖放／快捷键分别记录，不能彼此替代。证据标明源码与运行版、使用的目标和窗口、实际已测显示器／缩放范围；没有测过的 App、多屏或物理输入仍列待验，不用测试计数代替体验验收。

本轮已通过的真实 MCP 路锥预览、应用、撤回属于场景事务证据。被用户否定的 Blender 内部 GPU 高亮检查属于过程记录；两者均不能直接转记为新桌面 overlay 已验收或已部署。

当前实现：`ResultOverlay.swift` 统一呈现；`main.swift` 核对任务/阶段、输入时间与版本、真实 PID/CGWindowID 并管理失效；`result_geometry.py` 仅作 Blender 只读区域适配。原生组件检查使用 `pnpm --dir desktop-preview run test:result-overlay`，验证真实 panel 的不抢焦点/穿透属性、Retina/负坐标、重叠镂空和替换/超时清理；不把组件检查称为所有目标 App 的端到端验收。
